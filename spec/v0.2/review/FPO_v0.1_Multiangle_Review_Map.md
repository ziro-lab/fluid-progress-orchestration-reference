# FPO v0.1 Multiangle Review Map

## Mode
Hybrid: internal lens generation → external precedent/failure/boundary verification → independent results → relationship integration.

## Selected lenses

1. Purpose and boundary
2. Achievement vs operational state
3. Authority and user control
4. Failure diagnosis and recovery
5. Evidence and evaluation
6. Security and trust
7. Resources, context and liveness
8. Operations, maintenance and migration
9. Redundancy, compression and deletion test

## Integrated bottleneck

The Control Core is not the bottleneck. The uncontracted External Operational Plane is.

## Direct precedents

- A2A task lifecycle: useful for delegated operations, not for FPO achievement checkpoints.
- Agent evaluation practices: useful for repeated reliability and end-state validation.

## Structural analogues

- Temporal durable execution: crash/replay semantics.
- Erlang supervision: bounded restart intensity.
- Saga: compensation of partial effects.

## Failure-side precedents

- OWASP: untrusted content, output handling, excessive agency and unbounded consumption.
- Recent long-trajectory diagnosis papers: error cascades, root-cause localization and history compression.

## Boundary result

Strongly applicable:
- bounded digital work
- observable acceptance
- connected capabilities
- reversible or explicitly controlled side effects

Conditional:
- subjective creative work
- high-stakes domains
- large multi-work projects

Out of v0.x scope:
- continuous monitoring
- unconstrained physical-world autonomy
- goals without operationalizable acceptance
