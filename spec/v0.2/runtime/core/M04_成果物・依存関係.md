# M04_成果物・依存関係
## FPO v0.2 / module v0.3

### 役割

Artifact、step、Evidence、Effectの接続・依存・変更影響を確定し、必要な範囲だけを再処理できるようにする。

### 確定するもの

- stable component / step / artifact identities
- dependency graph and integration conditions
- change typeごとのinvalidated step / evidence / criterion / effect
- partial adoption boundaries
- current manifest and composition rules

### 原則

部分の正しさだけでなく、currentな全体接続を検証可能にする。
影響しない範囲を不要にinvalidにしない一方、依存先変更後のstale成果をcurrent扱いしない。

### 境界

OperationはM03、environmentはM02、verificationはM06へ任せる。
