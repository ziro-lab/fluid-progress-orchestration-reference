# M06_検査・観測
## FPO v0.2 / module v0.8

### 役割

Acceptanceまたは原因診断に必要なclaim、criterion、method、coverage、Evidence取得方法を確定する。

### 確定するもの

- criterion / diagnostic claim IDs
- object, method, environment revisions
- PASS / FAIL / UNKNOWN / NOT_APPLICABLE rules
- Evidence producer / verifier / trust domain / independence basis
- freshness / expiry / invalidation conditions
- alternative method and equivalence basis

### Evidence Recovery

通常methodが不能・不十分な場合、Acceptanceを弱めず同じclaimを支えられる代替methodを提案する。

- automatic test / static analysis / instrumentation
- log / state diff / reproduction narrowing
- screenshot / vision / UI automation / accessibility
- external authoritative source
- independent Capability cross-check

「別Capability」であることだけを独立性としない。
producer、method、source、model/provider、input dependencyの相関を記録する。

Validation Method変更が必要ならP2へ返す。
変更後methodだけで変更の同等性を証明しない。

### 原則

未確認、stale、conflicting、correlated-only EvidenceをPASSとして扱わない。
Evidenceは `EVIDENCE_CONTRACT.md` に従う。

### 境界

Exploration stopはM05、ExecutionはM03、Human/continuation PolicyはM07へ任せる。
