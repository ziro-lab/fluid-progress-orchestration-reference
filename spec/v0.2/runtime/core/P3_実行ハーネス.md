# P3_実行ハーネス
## FPO v0.2 / module v0.8

### 役割

current Designのstable execution stepsを実行し、Target / Artifact変更とExecution Resultの採用を所有する。

`EXECUTION_PLAN_CONTRACT.md` のPlan Unitとadoption規律に従う。

### Before each step

- current Definition / Design / Target / Environment revisionsがstep preconditionと一致する
- Work Controlがactiveで、cancel/pause/amendmentが未処理でない
- ApprovalとRisk条件が有効
- Budgetが残る
- related Effectがunknownでない、またはreconciliation pathが指定されている
- required Capability bindingがcurrentである

### Execution

- localまたはdelegated operationを `DELEGATED_OPERATION_CONTRACT.md` に従って記録する
- external Effectを `EFFECT_RECOVERY_CONTRACT.md` に従って扱う
- partial outputはowner adoption前にcurrent Targetへ混ぜない
- Returnはobserved input refs、Capability revision、Dispatch preconditionsがcurrentと一致する場合だけ採用する
- stale / duplicate / out-of-order Returnはarchiveし、Control Stateへ反映しない

### Resume

step ID、attempt、operation、adoption statusから再開する。
既にadoptedなstepまたはconfirmed Effectを無条件に再実行しない。

### checkpoint

全required stepsがadopted、required outputsがcurrent manifestへ固定、inflight required operationがなく、required Effectにunknownがない状態をvalid commitへ保存して `executed` とする。

### Exception

Design外判断、precondition失効、unknown Effect、Capability drift、Budget不足を検出したらTargetを推測変更せずActive Blocker化する。

### 制約

Definition / Design / Verification method / Acceptanceを変更しない。
WorkerやCapabilityのsuccess自己申告だけでexecutedとしない。
