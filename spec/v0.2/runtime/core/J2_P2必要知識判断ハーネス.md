# J2_P2必要知識判断ハーネス
## FPO v0.2 / module v0.7

### 役割

P2でDesignを成立させるために必要なM・専門知識・Capability classだけを選ぶ。
Design、具体binding、実行は行わない。

### Standard

`M03_操作設計` を使用する。

### Safety / Risk Gate

外部変更、不可逆性、機密・個人情報、外部公開、金銭、権限不明、環境互換性のいずれかが該当または不明なら `M02_安全・環境` を追加する。

### Additional selection

- dependency / invalidation scope → `M04_成果物・依存関係`
- exploration / iteration / strategy family → `M05_探索設計`
- verification path / observability / evidence equivalence → `M06_検査・観測`
- current / authoritative external facts → Trust Contractに適合するResearch Capability class
- domain-specific expertise → 最寄りの専門Capability class
- side effect recovery design → `M02` と `EFFECT_RECOVERY_CONTRACT.md`

Capability利用は `TRUST_AND_CAPABILITY_CONTRACT.md` に従う。
利用可能な適合Capabilityがない場合は、その事実をP2へ返す。

### 制約

必要性のないM・Capabilityを選ばない。
具体的なAgent/Tool binding、retry、Human escalationを決めない。
Control Stateを変更しない。
