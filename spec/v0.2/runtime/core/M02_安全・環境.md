# M02_安全・環境
## FPO v0.2 / module v0.5

### 役割

作業を許可されたRisk、情報、環境、Effect範囲内で実行するための保護条件を確定する。

### 確定するもの

- protected assets / prohibited scope
- environment and compatibility conditions
- data classification and handling scope
- authority / approval scope, target, revision, expiry, revocation
- risk tier and Human gate timing
- effect classification: compensatable / pivot / irreversible
- Risk Tier: T0 / T1 / T2 / T3。T3はv0.2自律admission対象外
- rollback, compensation, forward recovery, damage containment

### Risk boundary

Risk Tierの規範定義とv0.2自律境界は `WORK_CONTROL_CONTRACT.md` を正とする。M02は案件の事実をTierへ分類し、必要Gateを設計する。

### 原則

- 技術的に可能であることと実行許可を分ける。
- Human-LastはSafety、Authority、Risk gateを弱めない。
- Approvalは包括的な永続許可とせず、scope / revision / expiryを検証する。
- 不可逆・高影響操作は明示PolicyまたはApprovalなしに自律実行しない。
- 保護は注意書きだけでなく、Tool scope、path allowlist、sandbox、egress、Effect Contractで強制する。

### 境界

操作設計はM03、EvidenceはM06、Recovery PolicyはM07、Effect lifecycleはEffect Contractへ任せる。
