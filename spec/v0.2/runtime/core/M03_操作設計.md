# M03_操作設計
## FPO v0.2 / module v0.6

### 役割

P3が追加Design判断なく再開可能に実行できるstable step、operation、instructionへ変換する。

### 確定するもの

- stable step ID、dependency、owner、input/output refs
- target identity and revision checks
- Capability class、required interface、binding constraints
- local/delegated operation semantics
- attempt / strategy family / retry and cancel semantics
- adoption and invalidation conditions
- effect intent / idempotency / reconciliation refs
- start/finish evidence and resume point

### 原則

- stepは意味ある作業単位とし、不要に低レベル化しない。
- 同一logical intentと新attemptを区別する。
- partial outputはadoption前にcurrent Targetへ混ぜない。
- retryはBudget、Effect outcome、precondition、strategy familyを確認する。
- Capability existenceはAuthorityやApprovalを意味しない。

### 境界

SafetyはM02、dependencyはM04、explorationはM05、verificationはM06、具体binding/lifecycleはDelegated Operation Contractへ任せる。
