# M07_回復・引き継ぎ
## FPO v0.2 / module v0.6

### 役割

P5が持つBlockerについて、有限Budget・Safety・Risk・Progressに基づき、継続、戦略切替、待機、Human、terminal proposalのPolicyを決める。

M07は原因分類、Capability class選択、Control State更新を行わない。

### Policy order

必要十分な最小経路を選ぶ。

1. known safe treatment / adopted Evidence
2. diagnostic observation
3. trusted external research
4. appropriate specialist Capability
5. reversible bounded experiment / different strategy family
6. alternative Evidence / independent check
7. Human / external condition wait / terminal proposal

これは全件逐次実行手順ではない。

### Human-Last / Safety-First

Humanを呼ばないことを目的化しない。
機械で代替できる判断をHumanへ戻さない一方、Authority、Approval、不可逆性、高Risk、本人固有Preference、物理必須EvidenceではGateを前倒しする。

### Budget and No Progress

次を確認する。

- realized net Progress
- strategy family repetition
- remaining hard/soft budget
- cost / risk / debt increase
- Capability availability
- resume predicate

Hard budgetを超えない。
Progressなしで自律経路が尽きた場合、根拠付きでpause/approval待ち、分割、unsatisfiable/out_of_budget/safety_stop proposalを返す。

### Suspend / Resume

待機時は、必要event、approval、external condition、deadlineをresume predicateとして明示する。
無関係eventで再開しない。

### 境界

原因・能力選択はJ3、Evidence方法はM06、SafetyはM02、Blocker lifecycleとrollbackはP5、Work Control適用はRuntimeへ任せる。
