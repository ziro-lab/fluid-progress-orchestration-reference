# M05_探索設計
## FPO v0.2 / module v0.5

### 役割

一意に決まらない作業について、有限なstrategy family、attempt、採用・停止・切替規則を確定する。

### 確定するもの

- exploration scope
- strategy family IDs and material differences
- hypothesis / expected delta
- attempt budget and resource allocation
- comparison / adoption rules
- stop / switch / exhaustion conditions

### Progress rule

Strategy変更、Tool変更、新Capability利用はAttempt差分であり、Progressそのものではない。

Progressは対象BlockerまたはGoalにmaterialで、adoptedされ、次のnet changeを伴う場合だけ認める。

- valid Evidence / coverage増加
- uncertainty / cause candidates減少
- validity / recoverability増加
- 失効Evidence、cost、risk、debtを差し引いても正の変化

### 原則

同じstrategy familyを表層変更だけで繰り返さない。
Hard budgetを越えて探索しない。
既に得た有効成果を不要に失わない。

### 境界

実行はM03、dependencyはM04、measurementはM06、継続PolicyはM07へ任せる。
