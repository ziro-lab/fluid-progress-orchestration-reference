# J3_P5必要知識・能力判断ハーネス
## FPO v0.2 / module v0.7

### 役割

P5が所有するActive Blockerについて、原因候補を分類し、原因区別または解消に必要なM・知識・Capability classだけを選ぶ。

J3はRecovery strategy、retry継続、Suspend、Human escalation、checkpoint変更を決めない。

### Selection

- source / definition / intent fidelity → P1関連資料、必要ならM06とResearch Capability
- safety / environment / approval / effect → M02
- operation / target identification / execution instruction → M03
- dependency / invalidation / integration → M04
- search space / strategy family → M05
- evidence / observability / diagnostic discrimination → M06
- external current facts → trusted Research Capability class
- domain expertise → domain Capability class
- capability unavailable / unhealthy / incompatible → Trust and Capability Contractの代替class
- cause unknown → M06で仮説を区別する最小観測

### Safety Gate

診断・probe・recovery actionが外部変更、不可逆性、機密、権限、外部Effectを伴う可能性がある場合、M02を必ず追加する。

### Output

J3は次だけをP5へ返す。

- cause classification候補
- 必要なM
- 必要なCapability classと入出力要件
- 区別に必要な観測
- 利用不能・不適合の事実

### 制約

原因に直接関係しない能力を読み込まない。
修正、通常成果物変更、Design変更、Human選択、Control State変更を行わない。
