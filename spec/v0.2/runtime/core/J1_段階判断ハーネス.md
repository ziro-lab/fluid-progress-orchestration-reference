# J1_段階判断ハーネス
## FPO v0.2 / module v0.7

### 役割

Pre-routing Control Gateを通過した信頼済みWORK_STATEから、次のP段階だけを選ぶ。

### Routing

- `checkpoint = closed` かつ `interrupt_ref = null` → DONE
- closed矛盾、未知checkpoint、invalid projection → 段階を選ばずRuntime control fault
- `interrupt_ref != null` → `P5_進行回復ハーネス`
- `none` → P1 作業定義
- `defined` → P2 作業設計
- `designed` → P3 実行
- `executed` → P4 検証
- `accepted` → P6 終了・引き渡し

### 制約

- Work Control lifecycleを判断しない。J1前のRuntime Gateに任せる。
- Blocker原因、Recovery strategy、Capabilityを選ばない。
- checkpointの業務上の有効性を再判定しない。
- 次段階の作業を行わない。
